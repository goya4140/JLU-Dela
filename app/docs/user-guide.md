# JLU Dela 使用指南与须知

## 第一次使用

1. 阅读使用条款和隐私说明，再进入配置向导。未完成的向导会在下次启动时继续。
2. 按需配置模型。只看课表、通知、课程资料和本地知识库，可以先跳过模型配置。
3. 按需逐个配置校园平台。教务单独完成学校认证，可能需要微信验证；通知、学在吉大和学习通分别连接。学生邮箱可直接填写邮箱地址与邮箱密码，无需先登录教务。
4. 按需安装文档读取组件和扩展。没有使用需求时可以直接完成配置。

配置完成后，可在「设置 → 使用指南」重新查看说明、检查本机同步记录和连接平台；也可以从「吉大校园」进入。

## 校园平台与登录

| 平台     | 在 Dela 中可以做什么                                     | 登录方式                   |
| -------- | -------------------------------------------------------- | -------------------------- |
| 教务系统 | 同步本科课表、校历、节次和调停课信息                     | 吉大校园会话               |
| 电子校务 | 阅读已同步的校内通知和正文                               | 尝试复用吉大校园会话       |
| 学在吉大 | 读取课程与回放，在应用内看录像、字幕和记笔记             | 尝试复用吉大校园会话       |
| 学习通   | 读取课程、普通资料目录和作业列表，按需导入允许下载的文件 | 独立的超星会话，需单独连接 |
| 吉大邮箱 | 本机收发、检索邮件与阅读附件                             | 单独配置邮箱地址与密码     |

教务课表单独配置：「打开教务认证」用于完成学校登录、微信认证或验证码，通过后再同步；「同步课表」先使用现有会话，并尝试正常的统一认证恢复。需要本人验证时，再点击认证入口。可关闭认证窗口取消，不影响继续配置邮箱等其他平台。

电子校务和学在吉大各自连接，学校允许时复用已有校园会话；一次认证不代表所有平台都已连接。学习通使用独立会话，不复制吉大或其他浏览器的登录凭据。

校园网页平台只有点击连接或同步时才会访问。登录和验证码由你在对应平台的登录页面中完成，不需要交给 AI。会话保存在本机，退出重开后会尝试复用；学校会话过期、退出账号或要求再次验证时，仍需重新认证。校园网页接入不保存学校密码，也不延长服务端有效期。邮箱连接使用单独配置的邮箱密码，凭据加密保存在本机。

学生邮箱 `@mails.jlu.edu.cn` 可使用预设；教工邮箱及其他邮箱请选择「第三方 IMAP」，填写对应的收发服务器。邮箱同步保留服务器草稿，不会自动清空；草稿编辑与回收站由 Dela 本地管理。邮件会在启动后及后台定期同步，不属于校园网页的统一认证连接。

教务配置分别显示本机课表与本次操作结果。能查看已有课表，不代表这次同步成功或登录仍有效；请核对「上次课表更新」。学校认证通过但后续同步失败时，会分别提示，不把它们合称为登录失败。其他平台的「本机已有数据」只说明曾经成功同步，不代表当前仍处于登录状态。「本次连接成功」表示刚刚完成了实际读取，也不保证会话永久有效。连接失败会保留旧缓存；只覆盖当前同步范围的列表不会被当作整个平台的完整内容。

## 配置与使用 AI

在「设置 → 模型供应商」选择服务，填写服务地址、API Key 和模型，按需检测并保存。API Key 是模型服务的密钥，与校园账号密码不同。已经保存配置不等于当前网络或模型一定可用。

阅读资料时点击「引用并提问」，片段会进入对话草稿；补充问题后点击发送才会调用模型。模型请求可能包括对话历史、按需读取的资料、附件和工具结果，费用及数据处理方式取决于你选择的服务。资料在本机保存不代表模型推理离线。

AI 生成的解释和笔记需要核对来源。Agent 还具有读写文件、运行命令的能力；重要资料应保留备份，只启用自己信任的 Skills、MCP 或扩展。

## 从资料开始学习

**本地资料：** 打开「知识库 → 连接文件夹」，选择已有课程资料目录。进入某个课程文件夹后点击「设为课程」。连接过程保持文件原位，之后在工作台编辑或新建笔记会实际写入文件。浏览已连接文件夹时会同时列出文件，点击即可在工作台打开；课程卡片右上角的 ✕ 可取消课程，「断开连接」可移除整份知识库登记，两者只清理本机记录与 PDF 索引，磁盘文件、工作台项目和学习笔记都保留。

**网页资料：** HTML 文件默认按页面渲染，可在标签右上角切换到「源码」查看原始标记再切回。渲染在受沙箱限制的框架内进行，脚本不会执行；相对路径的图片和链接通过本机资源协议读取，无法解析时会给出提示。

**检索：** 输入关键词并搜索当前课程。文件名以及 2 MB 以内的 Markdown / TXT 正文可直接检索。PDF 先选择文件并点击「提取 PDF 正文」，再搜索正文、跳转到命中页；提取在本机进行，每份限 40 MB、300 页。扫描件、未提取的 PDF 和 Office 正文暂不在正文检索范围内。源文件更新后，需要重新提取 PDF。

**学习通资料：** 进入课程的「资料」页，打开普通文件夹，点击「导入并打开」。文件保存在资料工作台的「学习通资料」下。特殊「教师课件」入口暂未适配；作业卡片显示已读到的截止时间与倒计时；相对时间标注为上次同步的快照。点击「在工作台打开作业」可在桌面应用里查看和作答，提交由学习通原网页处理。

**学在吉大回放：** 同步课程，选择课程并读取回放目录，再打开录像。可切换平台提供的画面、搜索字幕、记录笔记和引用片段提问。字幕由学校提供；没有字幕时不会自动转写或收费。录像进度、笔记和对话分别保存。

**课堂课件：** 观课时点击「导入课件」选择老师发的 PPT、PDF 或 Office 文档，副本保存在工作区「课堂课件」目录，原文件不受影响。点课件名可在工作台打开；点右侧对话图标会把课件入口和当前播放位置写进 AI 草稿，由 AI 读取课件后再讲解，草稿需要你手动发送。点 ✕ 只取消这次登记，工作区里的副本保留。

## 连接或同步失败时

| 看到的情况                         | 建议操作                                                   |
| ---------------------------------- | ---------------------------------------------------------- |
| 学校页面要求登录或验证码           | 在该学校页面完成验证，再等待同步结果                       |
| 超时、断网或平台无法访问           | 检查网络和学校服务；校外按学校要求连接 VPN 后重试          |
| 页面结构变化、接口错误或访问被拒绝 | 保留现有会话和缓存，稍后重试；这些错误不自动等于登录过期   |
| 列表为空                           | 核对学期、课程和同步范围；空列表不等于已退出登录           |
| 模型不可用                         | 核对模型服务地址、密钥、模型名称和余额，不需要重登校园平台 |

各平台可以单独重试或跳过。教务报 403 不自动等于登录失效；若学校页面明确要求微信认证，通过「打开教务认证」完成。认证后仍报 403 时，请保留错误详情反馈，不要反复清除会话。

## 本机数据与当前范围

默认资料目录是 `~/Documents/JLU-Dela/`，应用状态和会话位于 `~/Library/Application Support/JLU-Dela/`。工作目录可在设置中查看和修改；原位连接的知识库继续使用你选择的目录。

当前为非官方开发预览，优先 macOS Apple Silicon。平台覆盖和已验证范围以各功能页与 README 为准。分享日志、截图或故障样例前，请去掉账号、密码、Cookie、验证码、密钥和个人校园数据。

## 学习日历

点击侧栏顶部的学习日历图标，按周、月或列表查看课程、作业和个人待办；可分别开关来源。课表沿用教务已同步的学期、教学周和节次，更新请进入课表页。

「刷新学习通作业」会逐门读取当前课程，必要时由你完成学校认证。列表或作业原网页中明确读到的绝对截止日期才进入日历；只有日期时不补具体时刻，相对时间和未提供截止日期的作业放在「截止时间待确认」中。详情显示平台原文和缓存时间；已读取页面不代表平台全部历史作业。

作业详情和课程作业列表都能打开对应的学习通网页标签，复用已保存的学习通登录。旧缓存首次打开时会尝试更新入口；需要登录时在标签内完成，完成后自动返回原作业。入口过期可点「恢复作业入口」，时间尚未读到可在作业详情页点「更新作业时间」。若学校页面不适合内嵌，可用右侧图标在浏览器打开，浏览器可能需要独立登录。

网页标签在本次运行中切换后保留填写内容；网页提示尚未保存时，关闭或退出会询问是否离开。退出前请在学习通保存草稿。点「分屏」可并排打开笔记或对话；「选中文字问 AI」仅把选区放入对话草稿，由你确认发送，不会读取或提交作答表单。

个人待办可以在详情中标为完成或编辑；课程作业的提交状态由学习通同步，不能在本地勾选提交。「同时显示在课表页」只控制个人待办是否也出现在独立课表视图中。
