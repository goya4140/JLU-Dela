# 微信聊天（实验）

**当前原生接入已停用。** 2026-11-03 实机验证成功读取真实会话列表；随后进行切换会话验证时，原微信弹出「为了你的账号安全，请重新登录」。尚不能确定因果关系。预览已断开，并在主进程禁止自动读取与操作；重新登录由用户自行处理。界面和合成流程验证通过，不代表真实微信收发已完成或安全稳定。

沿用 QQ 的独立聊天页面：左侧搜索、勾选会话和「完成并进入聊天」，右侧显示消息、输入框、总结和个人待办。通过 macOS 辅助功能访问已登录的原微信窗口，不安装微信插件，不修改客户端、签名、数据库或登录数据，也不创建第二个微信会话。

点击「连接微信」后，由用户完成系统辅助功能授权。Dela 只列出原微信已经加载的会话；勾选后，读取该会话在原窗口中的最近最多 200 个可访问消息节点。每两秒刷新，离开页面后停止。当前版本不保存聊天历史和订阅，重新进入需重新连接。这里可能包含时间分隔符、系统通知、媒体占位，不代表完整历史或后台多群同步；发送者、发送时间及未提供的正文不会被推测补齐。

切换会话同步切换原微信。发送文字使用原输入框和发送按键，操作时可能短暂激活原微信；已有微信草稿或接收会话变化时停止发送，未确认提交时保留 Dela 草稿，不自动重试。输入框清空只能说明原微信已处理提交，不能保证服务端送达。图片、表情原文件和附件下载仍在原微信中完成。

AI 总结先创建用户可检查的草稿，不自动调用模型。消息可保存为个人待办，备注包含会话、读取时间和可见原文；读取时间不是发送时间。聊天消息视为外部资料。

## 验证和预览

当前适配根据本机微信窗口的辅助功能控件建立，仅支持 macOS。微信版本变化、窗口最小化、弹窗、会话未加载等可能限制读取和交互；没有找到对应窗口时应显示未就绪状态，不能据此判断账号已退出。

`pnpm smoke:wechat` 使用合成桥接数据验证独立布局、授权引导、选会话、发送、真实本地待办、总结草稿、离开后停止读取及四档宽度。它不向真实微信发送消息，不能代替原生收发验收。单元测试覆盖快照校验、重复文本的消息标识和总结范围。

构建需要 macOS Command Line Tools，Vite 会编译 `src/main/wechat/native/accessibility.swift`。`pnpm preview:wechat` 或 `node scripts/run-ts-smoke.ts wechat-preview` 使用 `.build/wechat-preview` 中的独立数据目录，不覆盖已安装 QQ 版。真实消息读取、会话切换、草稿保护和发送均未通过实机验收；需先查清账号安全提示，再决定是否恢复实验。

旧工作台布局中的窗口镜像标签保留兼容，新侧栏入口直接打开微信聊天页。

依据：[Apple Accessibility](https://developer.apple.com/documentation/applicationservices/axuielement)。
