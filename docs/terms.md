# JLU Dela 使用说明

最后更新：2026-10-30

## 开发预览

JLU Dela 是基于开源 Dela 的非官方适配项目，面向吉林大学本科生。项目与吉林大学、上海交通大学及其院系、部门不存在官方隶属或授权关系。代码沿用 [GPL-3.0-or-later](https://github.com/goya4140/JLU-Dela/blob/main/LICENSE)，保留上游版权与许可；开源许可中的权利不因本说明而缩减。

当前优先 macOS Apple Silicon。课表、课程资料、通知和课程回放同步仍待接入，平台入口仅在系统浏览器中打开学校网站。不要把页面入口或计划中的功能理解为已完成的学校服务集成。

## 本地工作台与模型服务

项目、笔记、资料与应用状态保存在本机。Agent 的模型能力由你自行选择并配置的服务提供，相关请求、费用与服务条件取决于你的配置。发送给模型的内容及其他联网行为见隐私说明。

Agent 可以读写文件并运行终端命令；第三方 Skills、MCP 和 Pi 扩展可能具有与本机应用相同的权限。请只使用自己信任的扩展，审阅重要改动，并保留资料备份。

## 学校平台与资料

学校服务的使用范围由学校平台决定；请在你自己的访问权限内使用。后续接入功能会明确说明登录方式、读取范围和同步状态。当前版本不会代你登录吉大平台、提交教务操作或发布校务内容。

## 问题反馈

开发预览可能存在缺陷，模型输出和工具结果需要核对。通过 [本仓库 Issues](https://github.com/goya4140/JLU-Dela/issues) 反馈可复现的问题，不要公开提交账号凭据或个人校园数据。

上游原使用条款作为历史资料保存在 `docs/upstream-terms.md`；其中交大服务和原分发渠道的描述不代表吉大版当前能力。
