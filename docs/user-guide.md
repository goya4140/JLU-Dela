# JLU Dela 使用指南与须知

## 第一次使用

1. 阅读使用条款和隐私说明，再进入配置向导。未完成的向导会在下次启动时继续。
2. 按需配置模型。只看课表、通知、课程资料和本地知识库，可以先跳过模型配置。
3. 连接校园平台。点击「依次连接吉大平台」，按提示完成学校认证；学习通使用独立的连接入口。
4. 按需安装文档读取组件和扩展。没有使用需求时可以直接完成配置。

配置完成后，可在「设置 → 使用指南」重新查看说明、检查本机同步记录和连接平台；也可以从「吉大校园」进入。

## 校园平台与登录

| 平台     | 在 Dela 中可以做什么                                     | 登录方式                   |
| -------- | -------------------------------------------------------- | -------------------------- |
| 教务系统 | 同步本科课表、校历、节次和调停课信息                     | 吉大校园会话               |
| 电子校务 | 阅读已同步的校内通知和正文                               | 尝试复用吉大校园会话       |
| 学在吉大 | 读取课程与回放，在应用内看录像、字幕和记笔记             | 尝试复用吉大校园会话       |
| 学习通   | 读取课程、普通资料目录和作业列表，按需导入允许下载的文件 | 独立的超星会话，需单独连接 |

「依次连接吉大平台」会顺序读取教务、电子校务和学在吉大。应用先使用已有会话；学校允许统一认证通行时，可减少重复输入。不同网站是否还需要验证由学校决定，不能保证一次登录能打开所有网站。学习通不会复制吉大或其他浏览器的登录凭据。

只有点击连接或同步时才会访问这些平台。登录和验证码由你在对应平台的登录页面中完成，不需要交给 AI。会话保存在本机，退出重开后会尝试复用；学校会话过期、退出账号或要求再次验证时，仍需重新认证。应用不保存学校密码，也不延长服务端有效期。

指南中的「本机已有数据」只说明曾经成功同步，不代表当前仍处于登录状态。「本次连接成功」表示刚刚完成了实际读取，也不保证会话永久有效。连接失败会保留旧缓存；只覆盖当前同步范围的列表不会被当作整个平台的完整内容。

## 配置与使用 AI

在「设置 → 模型供应商」选择服务，填写服务地址、API Key 和模型，按需检测并保存。API Key 是模型服务的密钥，与校园账号密码不同。已经保存配置不等于当前网络或模型一定可用。

阅读资料时点击「引用并提问」，片段会进入对话草稿；补充问题后点击发送才会调用模型。模型请求可能包括对话历史、按需读取的资料、附件和工具结果，费用及数据处理方式取决于你选择的服务。资料在本机保存不代表模型推理离线。

AI 生成的解释和笔记需要核对来源。Agent 还具有读写文件、运行命令的能力；重要资料应保留备份，只启用自己信任的 Skills、MCP 或扩展。

## 从资料开始学习

**本地资料：** 打开「知识库 → 连接文件夹」，选择已有课程资料目录。进入某个课程文件夹后点击「设为课程」。连接过程保持文件原位，之后在工作台编辑或新建笔记会实际写入文件。

**检索：** 输入关键词并搜索当前课程。文件名以及 2 MB 以内的 Markdown / TXT 正文可直接检索。PDF 先选择文件并点击「提取 PDF 正文」，再搜索正文、跳转到命中页；提取在本机进行，每份限 40 MB、300 页。扫描件、未提取的 PDF 和 Office 正文暂不在正文检索范围内。源文件更新后，需要重新提取 PDF。

**学习通资料：** 进入课程的「资料」页，打开普通文件夹，点击「导入并打开」。文件保存在资料工作台的「学习通资料」下。特殊「教师课件」入口暂未适配；作业列表的时间提示是同步时的快照，作答与提交请前往学习通。

**学在吉大回放：** 同步课程，选择课程并读取回放目录，再打开录像。可切换平台提供的画面、搜索字幕、记录笔记和引用片段提问。字幕由学校提供；没有字幕时不会自动转写或收费。录像进度、笔记和对话分别保存。

## 连接或同步失败时

| 看到的情况                         | 建议操作                                                   |
| ---------------------------------- | ---------------------------------------------------------- |
| 学校页面要求登录或验证码           | 在该学校页面完成验证，再等待同步结果                       |
| 超时、断网或平台无法访问           | 检查网络和学校服务；校外按学校要求连接 VPN 后重试          |
| 页面结构变化、接口错误或访问被拒绝 | 保留现有会话和缓存，稍后重试；这些错误不自动等于登录过期   |
| 列表为空                           | 核对学期、课程和同步范围；空列表不等于已退出登录           |
| 模型不可用                         | 核对模型服务地址、密钥、模型名称和余额，不需要重登校园平台 |

可以单独重试失败的平台。批量连接遇到需要人工处理的认证中断时，会停止后续步骤；处理完后再继续连接。

## 本机数据与当前范围

默认资料目录是 `~/Documents/JLU-Dela/`，应用状态和会话位于 `~/Library/Application Support/JLU-Dela/`。工作目录可在设置中查看和修改；原位连接的知识库继续使用你选择的目录。

当前为非官方开发预览，优先 macOS Apple Silicon。平台覆盖和已验证范围以各功能页与 README 为准。分享日志、截图或故障样例前，请去掉账号、密码、Cookie、验证码、密钥和个人校园数据。

## 学习日历

点击侧栏顶部的学习日历图标，按周、月或列表查看课程、作业和个人待办；可分别开关来源。课表沿用教务已同步的学期、教学周和节次，更新请进入课表页。

「刷新学习通作业」会逐门读取当前课程，必要时由你完成学校认证。列表中明确标注的绝对截止日期才进入日历；只有日期时不补具体时刻，相对时间和未提供截止日期的作业放在「截止时间待确认」中。详情显示平台原文和缓存时间；已读取页面不代表平台全部历史作业。

个人待办可以在详情中标为完成或编辑；课程作业的提交状态由学习通同步，不能在本地勾选提交。「同时显示在课表页」只控制个人待办是否也出现在独立课表视图中。
