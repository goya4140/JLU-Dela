# 本机网页端预览

网页界面连接本机 Dela harness，校园会话、模型密钥和 Agent 执行保留在本机。当前支持课表读取与同步、学习通课程/资料目录/作业状态、学校通知正文、学在吉大课程/录像/字幕及共用学习笔记，以及通用 AI 对话。录播目录优先使用缓存，可按需同步。同步确需人工认证时，操作本机的学校登录窗口。

先退出正在运行的桌面 Dela，再运行：

```sh
pnpm web
```

启动后打开 `.build/web-connection.json` 中的 `url`。首次连接链接只用于本机当前服务；浏览器连接后会移除地址中的凭据。关闭本机 harness 后网页不可继续请求。首次构建需要开发依赖，界面和本机服务由同一仓库构建。

网页当前不提供本地磁盘浏览、文件导入、终端或密钥管理。资料下载和模型配置继续使用桌面端。学校视频通过本机受限媒体入口代理，学习笔记通过不透明引用映射到本机相应录像的笔记，不接受任意本地路径。AI 由本机 Agent 执行；不等同于对 Agent 的文件工具做沙箱隔离。对话需要本机已配置模型，由用户点击发送；网页以轮询更新运行状态。

服务只监听 `127.0.0.1`，使用短期连接凭据与 HttpOnly、SameSite Cookie，不支持局域网、互联网或多用户部署。HTTP 接口按方法白名单开放，不转发任意 Electron IPC。

验证：`pnpm smoke:web` 使用人工数据检查浏览器独立运行、认证、五个功能页、视频播放、字幕引用、共用笔记保存及四档窗口宽度；单元测试另检查来源校验、参数和禁止的文件接口。
