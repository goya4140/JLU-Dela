# JLU Dela 隐私说明

最后更新：2026-10-30

## 本机保存

本项目没有自建账号服务或远程业务数据库。macOS 应用数据位于 `~/Library/Application Support/JLU-Dela/`，默认资料目录位于 `~/Documents/JLU-Dela/`，内置与自定义技能位于 `~/.jlu-dela/skills/`。工作目录可由你在设置中修改。

应用数据包括 SQLite 索引、会话 JSONL、设置、附件副本、缓存与条款接受记录。模型密钥等凭据由主进程使用 Electron safeStorage 加密保存，解密能力由操作系统保管。导出本地备份可能包含这些数据和凭据文件，请自行保管。

## 模型与外部工具

配置、检测或使用模型服务时，请求直接发往你配置的服务地址。会话历史、系统指令、按需读取的资料、你提交的附件和工具结果可能进入模型上下文；本地保存不代表模型推理离线。API 密钥由主进程放入相应服务的请求头，不作为聊天正文发送。

网络搜索、网页读取、第三方 MCP、Pi Packages、Skills 和终端命令可能访问外部服务；启用扩展时应核对其来源和行为。远程项目会通过你配置的 SSH 连接访问服务器。包和可选文档组件的安装会下载相关运行依赖。

## 吉大校园平台

课表、课程资料、学校通知与回放同步尚未接入。当前仅在系统浏览器中打开项目发起人提供的学校平台链接，应用不收集吉大密码、Cookie、令牌或个人校园数据。浏览器登录与网站的数据处理由相应学校平台负责。

## 更新与反馈

应用更新配置指向 `goya4140/JLU-Dela` 的 GitHub Releases；未打包开发运行不请求更新。正式签名更新链路仍待验证，当前仓库提供开发构建工作流。

主动提交 Issue、上传样例或分享日志会向你选择的平台公开或传送相应内容。请先脱敏，不要提交密码、令牌、个人成绩或完整会话记录。

上游原隐私条款作为技术参考保存在 `docs/upstream-privacy.md`，其中交大校园服务、旧数据路径与原更新分发源的描述不适用于当前吉大版。
